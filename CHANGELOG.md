# Change Log

All notable changes to the "context-link" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.2.5]

### Changed

- `format` setting is now machine-specific and will not be synchronized across devices with VS Code Settings Sync
- Updated README to document machine-specific format setting

## [0.2.4]

### Changed

- Default `pathType` changed from `relative` to `absolute`

## [0.2.2]

### Added

- `pathType` setting to choose between relative and absolute paths

## [0.2.0]

### Added

- `showNotification` setting to control toast visibility (off by default)

## [0.1.0]

### Added

- Published to VS Code Marketplace
- Added repository configuration

## [0.0.1]

### Added

- Copy context links with keyboard shortcut (`Ctrl+Alt+U` / `Cmd+Alt+U`)
- Support for Claude and OpenCode formats
- Context menu integration
